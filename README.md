# 로또 6/45 분석 · 번호 생성기

과거 당첨번호로 "예측 전략"이 실제로 통하는지 검증하고, 이번 회차 번호를 골라 주는 도구입니다.
파이썬 3.10 이상의 표준 라이브러리만 사용합니다.

```bash
python -m lotto update     # 동행복권에서 전 회차 당첨번호를 data/draws.csv 로 내려받기
python -m lotto analyze    # 번호별 빈도, 균일성 검정, 예측 전략 백테스트
python -m lotto pick       # 이번 주 회차 번호 5게임 생성 (--games, --draw, --seed)
python -m unittest         # 테스트
```

## 먼저 알아둘 점

로또 추첨은 매번 독립적인 균등 추첨이라, 어떤 조합이든 1등 확률은 **1/8,145,060**으로 같습니다.
과거 데이터로 다음 번호를 맞히는 모델은 원리상 무작위로 찍는 것보다 나을 수 없습니다.
`analyze`는 이를 직접 확인할 수 있게 해 줍니다.

- **균일성 검정**: 번호별 출현 횟수가 균등 추첨에서 기대되는 범위 안에 있는지 카이제곱 검정합니다.
  한 회차에 서로 다른 6개가 뽑히는 점을 반영해 통계량을 (N-1)/(N-K)배 보정합니다.
- **백테스트**: 최근 300회를 그 이전 이력만으로 예측해 1게임당 평균 일치 개수를 봅니다.
  어떤 번호를 고르든 이론 기대값은 0.8개, 3개 이상(5등 이상) 확률은 2.38%입니다.
  - `hot`: 최근 50회에 많이 나온 번호
  - `cold`: 가장 오래 안 나온 번호
  - `weighted`: 전체 출현 빈도에 비례해 추첨
  - `random`: 무작위 (비교 기준)

## `pick`이 하는 일

당첨 확률은 못 바꾸지만, **당첨됐을 때 상금을 나눠 가질 사람 수**는 번호 선택에 따라 달라집니다.
사람들은 생일(1~31), 연속 번호, 일정한 간격, 용지 위의 줄 모양, 지난주 번호를 많이 고르기 때문입니다.
`pick`은 균등하게 뽑은 조합 가운데 아래에 해당하는 것을 버립니다(전체 조합의 약 57%가 통과).

- 31보다 큰 번호가 2개 미만
- 연속 번호 3개 이상
- 등차수열 4개 이상 (예: 5, 10, 15, 20)
- 용지(7칸 × 7줄)의 같은 가로줄이나 세로줄에 4개 이상
- 과거 1등 조합 그대로, 또는 지난 회차 번호와 3개 이상 겹침 (`update` 후에만 적용)

또한 여러 게임끼리 겹치는 번호가 2개를 넘지 않게 해서 게임마다 다른 번호를 고르게 합니다.
